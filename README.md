# Profit & Loss Dashboard Analysis

## Project Overview
This project presents a high-level Profit & Loss (P&L) dashboard developed in Power BI to analyse financial performance, revenue trends, expenses, and profitability metrics.

The dashboard was designed to support business decision-making through interactive financial reporting and KPI visualisation.

---

# Objectives
- Analyse business revenue and expenses
- Monitor profitability trends
- Track key financial KPIs
- Support financial decision-making
- Deliver executive-level dashboard reporting

---

# Tools & Technologies
- Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualisation
- Financial Analytics
- Business Intelligence Reporting

---

# Dashboard Features
- Revenue analysis
- Expense tracking
- Profitability overview
- KPI performance monitoring
- Trend analysis and comparisons
- Interactive dashboard filtering

---

# Key Insights
- Identified major revenue and cost drivers
- Analysed profitability trends over time
- Highlighted opportunities for financial optimisation
- Supported data-driven financial reporting

---

# Business Impact
This project demonstrates how Power BI dashboards can support financial performance analysis, improve visibility into business operations, and assist stakeholders in making informed strategic decisions.
